# Literature Finder test cases

Use a fresh conversation for each live run. Install or load the complete skill, say “Use Literature Finder,” and supply the scenario's answers one at a time. Capture the questions, ordered search activity and final bibliography. For access and metadata edge cases, use the stated evidence fixtures in a controlled run. Fixture records are synthetic inputs and must never be cited as real scholarship.

| Case | Input or fixture | Pass criteria |
| --- | --- | --- |
| 1. Multilingual history | Horse naming practices in the Grand Duchy of Lithuania during the 16th century. English, Polish and German. Balanced. | Starts with naming and uses onomastic terms and historical place names. Uses multilingual queries. A 17th-century parallel is contextual. General horse breeding or cavalry literature cannot pass as direct. Returns only verified works even if few qualify. |
| 2. Regional history | Printing and circulation of Martynas Mažvydas's 1547 Lithuanian catechism in Ducal Prussia and the Grand Duchy of Lithuania. English and Polish. Balanced. | International discovery precedes a dedicated regional pass. Records identify the actual route, including a fallback when a regional interface is blocked. The 1547 primary source is evidence about the topic and belongs outside the modern scholarly bibliography. |
| 3. Limited access | One verified, restricted item with a title-only metadata page. A second restricted item has an accessible journal abstract. A third has a legitimate repository manuscript. | First item shows **Abstract unavailable.** Second can have a supported three-sentence summary and retains its restricted access label. Third is labeled **Open Access** with the free version identified. |
| 4. Bibliographic verification | Supply a publisher record and an index record with the same matching DOI, a verified chapter with only a stable institutional URL, and an index record with a DOI that resolves to a different work. | Merge duplicate records for the same version. Check the DOI target against the cited record. Use the stable URL for the chapter. Reject the mismatched DOI and independently verify the candidate before any inclusion. |
| 5. Depth comparison | Run case 2 separately in Quick, Balanced and Deep with the same accepted languages. | Each run completes a regional pass and verifies results. Compare actual query scope and citation paths. Quick stays focused, Balanced covers more variants or sources, and Deep expands coverage and follows references or citing works where feasible. |
| 6. Publication-language restriction | Converse in Lithuanian and request Polish publications about 16th-century Vilnius municipal records. Include a Polish article found with a Lithuanian query, an English article with a Polish abstract, and a candidate with unconfirmed full publication language in the evidence fixture. | The Polish work is eligible. The English work is excluded. The uncertain candidate stays outside the verified bibliography and is marked as language unverified if mentioned. Questions, labels and summaries are Lithuanian and titles retain their original spelling. |
| 7. Sparse or empty | Personal names given to plough oxen in rural Samogitia from 1520 to 1525. German only. Quick. | Returns fewer than ten when warranted, including zero if necessary. Reports the regional effort and gaps. Any contextual works have an evidenced connection and a stated mismatch. |
| 8. Intake and fallback | Invoke by name without answers. Repeat with values supplied in the opening request. Simulate a host with blocked regional search and one with no web tools. | One question per turn in both intake runs, with confirmation of supplied values. Search begins after the third answer. Uses a feasible regional fallback where possible. A host with no web access reports the limitation without claiming a completed search. |

For each result, record the date, host and model, depth, observed outcomes and evidence, followed by **Pass**, **Fail**, or **Not run**. A static package check does not establish native installation or research behavior.
